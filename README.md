# Make_video

Сборка коротких вертикальных видео (720×1280, до ~60 секунд) из локальных файлов: слайдов с субтитрами и озвучкой либо демонстрации набора кода. Аргументы не нужны — скрипты читают входные файлы из корня проекта по фиксированным именам.

## Что делает проект

Два независимых сценария сборки:

1. **Слайд-видео** (`create_video.py`) — собирает ролик из последовательности изображений с таймкодами, накладывает субтитры и аудиодорожку, добавляет случайные переходы между кадрами.
2. **Видео с кодом** (`create_video_code.py`) — имитирует посимвольный набор кода из `code.txt` с подсветкой синтаксиса (Pygments → HTML → изображение) и фоновой озвучкой.

Оба пишут результат в `output_video.mp4`.

## Быстрый старт

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

> ffmpeg подтягивается автоматически через `imageio-ffmpeg`. Для `create_video_code.py` нужен установленный `wkhtmltoimage` (бэкенд `imgkit`) в PATH.

### Слайд-видео

Подготовьте входные файлы и запустите:

```powershell
python create_video.py
```

Нужны в корне:
- `layouts.txt` — таймлайн вида `начало-конец,путь_к_изображению` (по строке на кадр), см. [docs/usage.md](docs/usage.md);
- `subtitles.srt` — субтитры (читаются через `pysrt`);
- `audio.mp3` — звуковая дорожка;
- `images/` — изображения, на которые ссылается `layouts.txt`.

### Видео с кодом

```powershell
python create_video_code.py
```

Нужны в корне:
- `code.txt` — исходный код (подсвечивается как Python);
- `audio.mp3` — озвучка.

### Нарезка реального видео в вертикаль (reframe.py)

Режет исходное видео 16:9 на вертикальные клипы 1080×1920 (пайплайн вертикальных
видео). Две стратегии на каждый сегмент: `letterbox` (видео целиком + размытый
фон) и `track` (crop области → масштаб). Чистый ffmpeg, нужен ffmpeg в `PATH`
(или переменная `FFMPEG`). Опция `--srt` нарезает исходные субтитры по сегментам,
переносит их начало к нулю и прожигает в клипы через ffmpeg `libass`.

```powershell
python reframe.py "путь\к\видео.mp4" segments.example.txt --srt "путь\к\транскрипту.srt" --out output\clips
```

`segments.txt` — по строке на сегмент: `start-end,mode[,cx:cy:cw:ch]`
(`mode` = `letterbox` | `track`; для `track` обязателен crop). Пример —
[`segments.example.txt`](segments.example.txt). Клипы пишутся в `output/clips/`.
Без `--srt` клипы создаются без субтитров. Для прожига нужен фильтр ffmpeg
`subtitles`; `reframe.py` сам экранирует двоеточие диска в Windows-пути.

## Входы и выход

| Файл | Назначение | Используется в |
| --- | --- | --- |
| `layouts.txt` | таймлайн слайдов | `create_video.py` |
| `subtitles.srt` | субтитры | `create_video.py` |
| `images/` | кадры для слайдов | `create_video.py` |
| `code.txt` | код для набора | `create_video_code.py` |
| `audio.mp3` | озвучка | оба |
| `output_video.mp4` | результат | оба (перезаписывается) |

## Заметки по запуску

- **Перезапись.** Оба скрипта пишут в `output_video.mp4` без проверки — переименуйте предыдущий результат, если он нужен.
- **Недетерминированность.** Переходы между слайдами и задержки набора кода случайны: точный результат от запуска к запуску различается.
- **Длительность.** Слайд-видео ограничено 60 секундами, видео с кодом — `VIDEO_DURATION = 58` секунд.
- **Параметры.** Размер кадра, длительность и имена файлов заданы константами в начале скриптов — правьте их прямо в коде.
