# Типовые проблемы

## Не найден ffmpeg

**Симптом:** `create_video.py`/`create_video_code.py` падают при обработке видео/аудио,
или `reframe.py` завершается с `ffmpeg не найден. Добавьте его в PATH или задайте
переменную окружения FFMPEG.`

**Причина:** `create_*`-скрипты используют ffmpeg через `imageio-ffmpeg` (ставится
вместе с зависимостями), а `reframe.py` — напрямую через `subprocess`, ищет
исполняемый файл сам.

**Решение:** для `reframe.py` — установить ffmpeg и добавить в `PATH`, либо задать
переменную окружения `FFMPEG` (см. [docs/configuration.md](configuration.md)).

## `create_video_code.py` падает на генерации изображения (imgkit/wkhtmltoimage)

**Симптом:** ошибка при вызове `imgkit.from_string(...)` или
`FileNotFoundError: Temporary image file was not created.`

**Причина:** `imgkit` — это обёртка над внешним бинарником `wkhtmltoimage`,
который не устанавливается через `pip install -r requirements.txt` — его нужно
поставить отдельно и добавить в `PATH`.

**Решение:** скачать и установить `wkhtmltoimage` (часть пакета wkhtmltopdf),
проверить `wkhtmltoimage --version` в консоли, затем повторить запуск.

## Субтитры/код не читаются или превращаются в «кракозябры»

**Симптом:** русский текст в `subtitles.srt`, `code.txt` или сгенерированных
файлах отображается неверно (mojibake) либо скрипт падает на чтении файла.

**Причина:** `create_video.py` читает `subtitles.srt` через `pysrt`,
`create_video_code.py` — `code.txt` через `open(..., encoding='utf-8')`. Если
исходный файл сохранён не в UTF-8 (например, Windows-1251 из старого редактора),
чтение даёт мусор или исключение.

**Решение:** сохранять `subtitles.srt` и `code.txt` в UTF-8 (без BOM). При
сомнениях в кодировке — использовать `/encoding-guard`.

## Результат каждого запуска немного отличается

**Симптом:** визуальный ряд (переходы между слайдами) или скорость «набора»
кода отличаются между двумя запусками с одними и теми же входами.

**Причина:** это ожидаемое поведение, а не баг — `create_video.py` и
`create_video_code.py` используют `random`/`random.uniform` для переходов между
слайдами и задержек между символами при наборе кода. Точный побитовый результат
не воспроизводится без правки констант/сида в коде.

**Решение:** если нужен детерминированный результат — зафиксировать `random.seed(...)`
в коде вручную (в текущей версии скриптов это не вынесено в константу).

## Пропадает видео или звук при нарезке через `reframe.py`

**Симптом:** в клипе `output/clips/...` отсутствует видеодорожка или звук
обрезан не там, где ожидалось, при указании смещения начала сегмента.

**Причина:** известный нюанс ffmpeg с `-filter_complex`: если задавать длительность
через output-side `-t`, может пропасть видео; если задавать её через input-side
`-t`, может пропасть звук.

**Решение:** уже учтено в `reframe.py` — для ненулевого начала сегмента
используется только input-side `-ss`, а нужная длительность обеспечивается
фильтрами `trim`/`atrim` с последующим сбросом PTS. Если вы правите `reframe.py`
вручную — сохраняйте эту схему.

## Прожиг субтитров (`--srt`) не находит файл на Windows

**Симптом:** ffmpeg-фильтр `subtitles=...` не может открыть путь к временному
SRT-файлу на Windows.

**Причина:** двоеточие диска (`C:`) в пути, переданном в фильтр `subtitles`,
ffmpeg интерпретирует как разделитель опций фильтра, а не часть пути.

**Решение:** уже учтено в `reframe.py` — путь к временному SRT экранируется
(`C\:/...`) перед подстановкой в фильтр. Если пишете собственный вызов ffmpeg —
экранируйте двоеточие диска так же.

## Прочие типовые причины сбоя

- **Не найден входной файл** — `layouts.txt`, `subtitles.srt`, `audio.mp3`,
  `code.txt` или файлы из `images/` отсутствуют в корне проекта. Скрипты
  ожидают эти файлы по фиксированным именам, а не как аргументы командной
  строки — проверьте их наличие перед запуском.
- **Нехватка памяти** на длинных/тяжёлых входных медиафайлах — уменьшите
  длительность/разрешение исходников для локального теста.
- **Аудио/видео/скриншоты могут содержать приватный контент** — не копируйте
  содержимое медиафайлов в документацию или тикеты, только пути и описания.
