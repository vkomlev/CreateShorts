# Конфигурация

Проект не использует `.env` — единственная переменная окружения задаётся
напрямую в окружении шелла перед запуском.

## Переменные окружения

| Переменная | Обязательна | Назначение |
| --- | --- | --- |
| `FFMPEG` | Нет | Путь к исполняемому файлу `ffmpeg`, который использует `reframe.py`. |

### `FFMPEG`

`reframe.py` ищет ffmpeg в таком порядке (см. `find_ffmpeg()` в `reframe.py`):

1. Переменная окружения `FFMPEG` — если задана и путь существует, используется он.
2. Иначе — `ffmpeg` из `PATH` (через `shutil.which`).

Если ни то, ни другое не найдено — скрипт завершается с ошибкой
`ffmpeg не найден. Добавьте его в PATH или задайте переменную окружения FFMPEG.`

Задать переменную:

```powershell
$env:FFMPEG = "C:\tools\ffmpeg\bin\ffmpeg.exe"
python reframe.py video.mp4 segments.txt --out output\clips
```

Скрипты `create_video.py` и `create_video_code.py` эту переменную не читают —
им ffmpeg подтягивается автоматически через зависимость `imageio-ffmpeg`.
