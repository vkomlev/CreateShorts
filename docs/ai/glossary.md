# Глоссарий

Доменные термины проекта Make_video. Только то, что реально используется в
коде/docs — без выдумывания терминологии.

## layouts.txt-таймлайн

Формат входного файла `layouts.txt` для `create_video.py`: CSV-подобный
таймлайн слайд-видео, по одной строке на кадр —
`начало-конец,путь_к_изображению` (секунды от старта видео). Читается
построчно в `create_video.py`; полное описание формата и пример —
[../usage.md](../usage.md).

## Сегмент

Единица нарезки в `segments.txt` — входном файле `reframe.py`. Одна строка
файла = один сегмент: `start-end,mode[,cx:cy:cw:ch]`, где `start-end` —
диапазон времени в исходном видео (секунды или `H:MM:SS`), а `mode` —
стратегия рефрейминга (см. ниже). Разбор — `parse_segments()` в `reframe.py`;
каждому сегменту на выходе соответствует один файл-клип в `output/clips/`.

## Letterbox / track (стратегии reframe)

Две стратегии `reframe.py` для превращения кадра 16:9 в вертикальный 9:16
(1080×1920), выбираются per-сегмент полем `mode` в `segments.txt`:

- **letterbox** — исходное видео вписывается целиком по ширине 1080, сверху и
  снизу — размытый (`boxblur`) фон вместо чёрных полос. Не требует `crop`.
- **track** — из исходника вырезается (`crop`) заданная прямоугольная область
  `cx:cy:cw:ch`, затем масштабируется до 1080×1920. Обязателен `crop` в
  `segments.txt`.

Реализация — `reframe_segment()` в `reframe.py`; контракт формата
`segments.txt` и обоснование двух стратегий — ADR-0003 (ContentFactory,
tsk-099), см. также [../ai/PROJECT_MEMORY.md](PROJECT_MEMORY.md).
