# Использование

## Формат `layouts.txt`

Текстовый таймлайн слайдов, по одной строке на кадр:

```
начало-конец,путь_к_изображению
```

- `начало` и `конец` — секунды от старта видео (дробные допустимы);
- путь — относительно корня проекта.

Пример:

```
0.0-5.4,images/image0.jpg
5.4-9.0,images/image1.jpg
9.0-18.7,images/image2.png
```

Поддерживаются форматы `.jpg/.jpeg/.png/.webp`. Изображения масштабируются под `720×1280` с сохранением пропорций.

## Субтитры

`subtitles.srt` — стандартный SRT, читается через `pysrt`. Стиль задаётся словарём `subtitle_style` в конце `create_video.py`:

```python
subtitle_style = {
    'color': 'yellow',
    'font': 'Arial',
}
```

Позиция по умолчанию — `('center', 'bottom')`. Шрифт должен быть доступен в системе (через ImageMagick/moviepy `TextClip`).

## Константы скриптов

Правятся прямо в начале файлов:

| Константа | Файл | Назначение |
| --- | --- | --- |
| `VIDEO_WIDTH`, `VIDEO_HEIGHT` | оба | размер кадра (720×1280) |
| `VIDEO_DURATION` | `create_video_code.py` | предел длительности (58 с) |
| `FONT_SIZE` | `create_video_code.py` | размер шрифта кода |
| `BACKGROUND_COLOR` | `create_video_code.py` | цвет фона `(35, 35, 35)` |
| `MAX_INTERVAL` | `create_video_code.py` | макс. задержка набора символа |
| `TEXT_FILE`, `AUDIO_FILE` | `create_video_code.py` | имена входных файлов |

## Зависимости от внешних бинарников

- **ffmpeg** — через `imageio-ffmpeg` (ставится с зависимостями).
- **wkhtmltoimage** — нужен `imgkit` в `create_video_code.py` для HTML→PNG. Установить отдельно и добавить в PATH.
- **ImageMagick** — может требоваться moviepy для `TextClip` (субтитры) в зависимости от окружения.

## Smoke-проверка

1. Подготовьте минимальные входы (1–2 кадра / короткий `code.txt`).
2. Запустите соответствующий скрипт.
3. Убедитесь, что `output_video.mp4` создан и не пустой.
4. Откройте первые/последние секунды — проверьте читаемость субтитров и кадров.
